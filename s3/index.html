My workflow

How I build and publish a page:

  1. Write the HTML structure in Visual Studio Code
  2. Move the styles into style.css and link it
  3. Test the page locally with Live Server
  4. Inspect the structure with Developer Tools
  5. Commit and push the changes to GitHub Pages
